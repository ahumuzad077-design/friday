## 🎮 HOW TO USE FRIDAY

### Mode 1: Interactive Command Center
```bash
node friday-command-center.js
```
Choose from 18 different operations:
- Make autonomous decisions
- Create and execute tasks
- Spawn and manage agents
- View real-time metrics
- Access all features interactively

**Best for:** Testing, training, exploration

### Mode 2: Automated Daemon (24/7)
```bash
node friday-daemon.js
```
Runs continuously in background:
- Auto-executes scheduled tasks
- Makes autonomous decisions
- Optimizes resources
- Reports metrics
- Zero human intervention

**Best for:** Production operations

### Mode 3: Programmatic Integration
```javascript
const { FridayCommandCenter } = require('./friday-command-center');
const friday = new FridayCommandCenter();
friday.decisionEngine.makeAutonomousDecision('situation');
```
**Best for:** Embedding in your applications
