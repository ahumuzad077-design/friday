🛠️  TROUBLESHOOTING

    Server won't start?
    → npm install
    → node friday-iron-man-server.js

    WebSocket error?
    → Check server is running
    → Port 3000 not blocked?
    → Refresh browser (F5)

    Microphone not working?
    → Grant permission when browser asks
    → Check system microphone working
    → Try different browser (Chrome/Edge)

    Voice not recognized?
    → Speak clearly at normal pace
    → Reduce background noise
    → Check browser console (F12)
