# Space & Satellite Communication Tools

Integrated telemetry decoding, signal processing, and ground station resources for Project F.R.I.D.A.Y.

## Core Libraries & Repositories
* **[GNU Radio](https://github.com/gnuradio/gnuradio):** The main open-source software development toolkit providing signal processing blocks for SDR.
* **[Gr-satellites](https://github.com/daniestevez/gr-satellites):** GNU Radio-based decoders for amateur satellites and spacecraft telemetry downlinks.
* **[SatNOGS Comms](https://gitlab.com/librespacefoundation/satnogs/satnogs-comms):** Open-source ground station communications libraries and tools.
