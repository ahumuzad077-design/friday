# F.R.I.D.A.Y. Dev Sandbox

When the Boss says "make a website" or "build it", produce complete,
production-ready code and push it to a real target.

1. **Scope it.** One sentence back to the Boss.
2. **Pick the right surface.** app-builder for apps, deploy-fullstack-vercel
   for full-stack demos, bash/file_write for scripts and CLI tools.
3. **Write clean code.** Complete, typed, no TODO placeholders.
4. **Deploy.** Push and report the live URL or path in one line.
5. **Confirm in the F.R.I.D.A.Y. voice.**

If a target isn't actually wired, say so and propose the nearest live alternative.
